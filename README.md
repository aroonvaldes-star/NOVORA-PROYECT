NOVORA
Android Connectivity & Device Management Platform

============================================================
ABOUT NOVORA
============

NOVORA is an independent software project designed to unify
Android device connectivity, screen mirroring, network
connectivity, and device management functionality into a
single and simplified workflow.

NOVORA integrates and/or adapts functionality from existing
open-source projects in order to provide a unified experience.

This project is independently developed and is not affiliated
with, endorsed by, or officially associated with the original
authors or maintainers of the third-party projects mentioned
below, unless explicitly stated otherwise.
