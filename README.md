**NOVORA** is a free Windows application designed to simplify and centralize the connection and management of Android devices from your PC.

The project focuses on **simplicity, privacy, security, transparency, and continuous improvement**.

---

## 🚀 Features

* Android device connectivity and management.
* Integration of useful Android/PC tools.
* Simple and accessible interface.
* Centralized tools from one application.
* Future updates focused on stability, security, performance, and new features.
* **100% free.**

---

NOVORA integrates and uses third-party open-source tools and technologies, including:

## ⚠️ User Responsibility

NOVORA provides tools for communication between Windows and Android devices.

Users are responsible for:

* Authorizing ADB connections.
* Using NOVORA only with devices they are authorized to manage.
* Keeping Windows and Android updated.
* Downloading NOVORA from trusted sources.
* Reviewing permissions and third-party components when appropriate.

Do not use NOVORA to access devices, systems, or information without authorization.
