# NOVORA 1.1

NOVORA es una aplicación para Windows orientada a la conexión y gestión de dispositivos Android, centralizando herramientas como ADB, scrcpy y Gnirehtet.

## Estado

Esta documentación corresponde a **NOVORA 1.1**.

## Características documentadas

- Conectividad y gestión de dispositivos Android.
- Integración con ADB.
- Integración con scrcpy.
- Integración con Gnirehtet.
- Interfaz de escritorio basada en C# + WPF/XAML.
- Herramientas centralizadas desde una aplicación de Windows.
- Enfoque en estabilidad, seguridad y futuras mejoras.

## Herramientas de terceros

NOVORA utiliza herramientas y tecnologías de código abierto de terceros, entre ellas:

- **scrcpy** — Genymobile.
- **Gnirehtet** — Genymobile / Romain V.
- **Android Debug Bridge (ADB)** — ecosistema de desarrollo Android.
